SmechOS 1.0 Release Candidate 2

Release Candidate -- Latest

Pins to the Plasma 6.6 LTS line (Frameworks 6.24, backed by Techpaladin Software + Kubuntu Focus + KDE e.V. through ~2029) instead of the latest Plasma point release, trading bleeding-edge for a stable target while the base system stabilizes. Fixes a chain of boot-critical bugs found since RC1 (kernel module loading, D-Bus system accounts, squashfs compression corruption, Calamares autostart/branding). Ships spk 2.1.0, with support for multiple package repos and pkg.smech.xyz -- SmechOS's first independent package repo, no longer solely dependent on GitHub Releases.

SmechOS 1.0 Release Candidate 1

Release Candidate

Bootable live ISO with KDE Plasma 6 running on a systemd + glibc base, with a working autologin straight to desktop -- verified on real hardware. Includes Google Chrome, Plasma Discover (backed by the SPK PackageKit backend), and the Calamares graphical installer to optionally commit to disk. Three GRUB boot entries: Live, Live (nomodeset), and Install via Calamares.

Verifying Your Download
