SmechOS -- Founder Anniversary Edition

Special Edition -- Cosmetic Only

Smech marks RC3's close with the Founder Anniversary Edition -- a cosmetic send-off for the Peritos family (est. 2026-06-25 -- 2026-10-06): a new wallpaper, a GRUB boot theme, a fastfetch logo, and a few hidden surprises layered on top of an already-verified RC3 rootfs. Same binaries as RC3 -- same Plasma 6.6.6 LTS (Frameworks 6.24.0), same spk 2.1.0, same boot fixes. No code changed, no new RC number. Just a proper goodbye to the family that got SmechOS this far, before SmechOS's own cross-toolchain takes over in RC4.

SmechOS 1.0 Release Candidate 3

Release Candidate -- Latest

A full boot regression fix. RC2's ISO built successfully but never reached a working desktop -- this release root-causes and fixes every layer of that: a missing Mesa/GBM library, a never-regenerated dynamic linker cache, missing systemd user D-Bus units that left the entire graphical session invisible to systemd, Qt plugin paths never propagated into independently-started session services, a missing xrdb, a missing libdecor that silently prevented Xwayland from starting at all (the real cause of kcminit/ksmserver hanging for 90 seconds each), and fontconfig being entirely absent from the image (every piece of desktop text rendered as a tofu box). All confirmed via a real, visually-verified boot to a working "Welcome to Plasma Desktop" first-boot wizard, and permanently fixed in the build pipeline itself, not just patched onto this ISO. Still pins to the Plasma 6.6 LTS line (Frameworks 6.24) and ships spk 2.1.0 with pkg.smech.xyz support.
